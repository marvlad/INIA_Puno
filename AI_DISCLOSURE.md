## AI Assistance Disclosure

Artificial intelligence tools, including **OpenAI LLM**, were used as assistive tools during parts of the development and documentation of this project.

AI assistance included tasks such as:

- Code review and debugging suggestions.
- Code organization and refactoring.
- Documentation and README preparation.
- Grammar and technical-writing improvements.
- Assistance with explaining and documenting the software workflow.

AI tools were used to support the development process rather than as autonomous developers. The project architecture, scientific methodology, data-processing workflow, fertilizer-recommendation logic, configuration, testing, and final implementation remain the responsibility of the project author(s).

Where AI-generated suggestions were incorporated into the repository, they were adapted to the requirements of the **INIA Puno soil-analysis and fertilizer-recommendation workflow**.
